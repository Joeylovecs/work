how many years ago was the new york americans founded?

Looking at the table, the earliest year listed is 1931. Assuming that's the founding year, we can calculate how many years ago that was from the current year.

import pandas as pd
from datetime import datetime

# Get the earliest year from the 'Year' column
# Extract numeric year from various formats (e.g., "1931", "Spring 1932", "1933/34")
def extract_year(year_str):
    # Find all 4-digit numbers in the string
    import re
    matches = re.findall(r'\b\d{4}\b', str(year_str))
    if matches:
        return int(matches[0])
    return None

# Apply the function to extract years
df['extracted_year'] = df['Year'].apply(extract_year)

# Find the minimum year (founding year)
founding_year = df['extracted_year'].min()

# Calculate years ago from current year
current_year = datetime.now().year
years_ago = current_year - founding_year

answer = years_ago
