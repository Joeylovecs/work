===================Question===================
1 / 3 of the away teams had a score greater than 10
===================Text===================
~~~python~~~
# Extract away team scores from the "away team score" column
# The scores are in format like "9.11 (65)". We need the numeric part inside parentheses.
# We'll extract the numeric score (the total points) from the parentheses.
df['away_score_numeric'] = df['away team score'].str.extract(r'\((\d+)\)').astype(int)

# Count total number of away teams (each row is one game, so number of rows)
total_away_teams = df.shape[0]

# Count number of away teams with score > 10
away_teams_gt_10 = (df['away_score_numeric'] > 10).sum()

# Check if exactly 1/3 of away teams have score > 10
# Since we are dealing with integer counts, we need to check if away_teams_gt_10 equals total_away_teams / 3
# But total_away_teams might not be divisible by 3, so we check if the proportion equals 1/3.
# However, the question says "1 / 3 of the away teams", which implies exactly one third.
# We'll compute the fraction and compare to 1/3 with a tolerance for floating point.
is_one_third = abs(away_teams_gt_10 / total_away_teams - 1/3) < 1e-9

answer = bool(is_one_third)
