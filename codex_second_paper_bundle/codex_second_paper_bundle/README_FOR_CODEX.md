# Files to give Codex

Recommended order:

1. `CODEX_MASTER_PROMPT.md` — the authoritative execution instruction.
2. `RESEARCH_METHOD_SPEC.md` — compact method definition and audit semantics.
3. `EXPERIMENT_PROTOCOL.md` — fixed data/testing/metric rules.
4. `API_SETUP_TEMPLATE.sh` — local shell template; insert the real key privately and never commit it.
5. The first-paper PDF (optional context) and, more importantly, read-only access to the first-paper code repository if the VS Code/Codex environment can see it.

Important:
- Paper-1 Windows repository is read-only.
- Paper-2 SSH Linux repository is the only writable workspace.
- Dataset format is already finalized by paper 1 and must not be redesigned.
